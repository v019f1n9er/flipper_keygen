# Flipper_kegen

## О проекте

> *Данный проект нацелен на генерацию паролей от 8 до 20 символов с использованием цифр, латинских заглавных и строчных букв с помощью Flipper Zero с дальнейшей возможностью печати на сторонне устройство через функционал BadUSB.*

---

Проект написан на `C`, основной файл проекта - `hello_flipper.c`, также присутствует файл манифеста приложения - `application.fam`.

Приложение состоит из 3 функций:
- `generate_password` - функция генерации пароля.
- `save_to_duckyscript` - функция сохранения результата генерации, позволяющая произвести симуляцию печати на стороннее устройство. Файл сохраняется по пути `/ext/badusb/generated_key.txt` (там же лежат "сценарии" BadUSB по-умолчанию).
- `hello_flipper_app` - основная функция программы, в которой вызываются две предыдущие функции, а также описывается функционал кнопок для расширенных возможностей.

---

## Сборка и установка

### 1. Подготовка окружения

Необходимо установить `ufbt` и загрузить актуальный SDK (подтребуется `python3`).

```
pip install ufbt
ufbt update
```

### 2. Сборка и запуск на устройстве

1) Необходимо подключить Flipper Zero к ПК по USB-кабелю (убедитесь, что закрыт qFlipper, чтобы COM-порт был свободен).
2) В корневой папке проекта выполните команду:
```
ufbt launch
```
Скрипт скомпилирует бинарный файл `.fap`, загрузит его на SD-карту в директорию `/ext/apps/Examples/` и автоматически запустит на экране устройства.

(Если требуется только скомпилировать файл без подключения Flipper, используйте команду `ufbt` - готовый `.fap` появится в папке `dist/`).

## Использование

1. Запустите приложение на Flipper Zero (`Apps` -> `Examples` -> `App hello_flipper`).
2. Используйте кнопки управления на экране:
   - Левая кнопка (`- Len`) - уменьшить длину ключа (минимум 8 символов) и сгенерировать новый.
   - Центральная кнопка (`OK / New`) - сгенерировать новый ключ текущей длины.
   - Правая кнопка (`+ Len`) - увеличить длину ключа (максимум 20 символов) и сгенерировать новый.
   - Кнопка Назад - выход из приложения.
4. Для автоматического ввода сгенерированного пароля на ПК или смартфон перейдите в главное меню Flipper: `BadUSB` -> `generated_key.txt` -> `Run`.
